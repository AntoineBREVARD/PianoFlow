🎹 PianoFlow

Apprends le piano, du premier Do jusqu'à tes morceaux préférés. Aucune partition à lire : les notes tombent, tu les suis.

Ajouter le morceau que tu veux

Télécharge le fichier trouvé, puis importe-le ci-dessous — ou, avec l'appli installée, utilise Partager → PianoFlow depuis tes Téléchargements : le morceau s'ajoute tout seul. Ensuite, « Apprendre pas à pas » le découpe en étapes.

Importer une partition

Dans MuseScore : Fichier → Exporter → MusicXML compressé (.mxl) ou MIDI. L'appli MuseScore Studio est gratuite ; seuls les téléchargements depuis musescore.com demandent un abonnement — voir les sources gratuites plus bas.
